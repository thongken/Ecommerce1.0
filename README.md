# Ecommerce1.0

A full-featured e-commerce web application built as a group project. The app supports two main user roles — Customer and Admin — each with their own features and views.

---

## Tech Stack

- Frontend: React, TypeScript, JavaScript, CSS
- Tooling: Node.js / npm
- UI: Reusable components and responsive layouts
- API Services: Product, Cart, Order, Voucher, User, Payment, Review, and Location services

---

## Getting Started

```bash
# Clone the repository
git clone https://github.com/thongken/Ecommerce1.0.git

# Move into the frontend folder
cd Ecommerce1.0/frontend

# Install dependencies
npm install

# Start the development server
npm start
